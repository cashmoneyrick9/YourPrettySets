# Home Page Brief

The Home page is the first page to build and the visual reference for all future pages.

It should be a polished long-scroll page, but every section should earn its place. The page should feel browseable, pretty, and structured.

## Goals

- Establish YourPrettySets as a handmade ready-to-wear press-on nail brand.
- Make visitors want to browse.
- Show many products without clutter.
- Define the site visual language for future agents.
- Use central placeholder product data.

## Section Order

### 1. Hero

Purpose:

- Introduce the brand.
- Show a seasonal product spread.
- Push users toward shopping ready-to-wear sets.

Content direction:

- Brand name: YourPrettySets
- Tagline direction: Art on Miniature Canvases
- Supporting copy should explain handmade ready-to-wear press-on nails without sounding overdone.
- CTA should point to the ready-to-wear shop/collection.

Visual direction:

- Clean product spread with several nail sets.
- Spring/summer color accents.
- Product should be visible and central.

### 2. New Arrivals

Use a product carousel.

Pull from central product data using `New Arrivals` or `isNew`.

Cards should show:

- Clean product image
- Product name
- Price

### 3. Shop By Collection

Show collection entry points or filter-style cards.

Collections:

- Everyday
- Date Night
- Vacation
- Bridal
- Birthday
- Work/Neutral
- Statement

This section should make browsing by occasion feel natural.

### 4. Featured Sets

Use another carousel or visual product row.

Can pull from products tagged as:

- Popular
- Statement
- Seasonal
- Detailed

Exact logic can be placeholder-based.

### 5. What's Included

Show the kit contents:

- 24 nails
- Adhesive tabs
- Nail glue
- Nail file
- Cuticle pusher
- Alcohol wipe
- Application card
- Storage box or bag

Keep the section visual and easy to scan.

### 6. How It Works Preview

Short version only.

Suggested flow:

- Choose your set.
- Pick length and shape.
- Apply with glue or tabs.
- Wear, remove, and store with care.

Copy should be refined later. Avoid sounding generic or clunky.

### 7. Reviews

Use realistic placeholder reviews.

Tone:

- Mix of everyday customers and beauty/lifestyle shoppers.
- Friendly and believable.

Do not pretend these are verified real reviews.

### 8. FAQ Teaser

Show a few common questions and link to the full FAQ page.

Keep it short.

### 9. Footer

Include:

- Navigation
- Contact placeholders
- Instagram placeholder
- Policy links/placeholders

## Mobile Direction

Use both browsing patterns:

- Home: swipe/browse carousels.
- Shop page later: practical product grid with filters/search/sort.

Mobile should feel fast, visual, and easy to scan.
